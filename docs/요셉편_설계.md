# 요셉 편 · 꿈꾸는 자 — 설계 문서 (v9, 약속의 길 v8 엔진)

> 야곱 편과 같은 v8 엔진(「약속의 길」) 위에 다시 지은 요셉 편입니다. 예전 요셉 편(「족장의 길」 엔진, 5장·27스텝)의 이야기 뼈대를 살리되,
> 프롤로그 튜토리얼·구덩이·대상 행렬·보디발의 집 생활·옥중의 이 년을 크게 늘리고, 컷신·배경음악·한국어 더빙을 더했습니다.
> 본문: 창세기 37:2–36, 39–41장, 42:1–9 (+ 시편 105:17–19, 창 42:21 회상, 창 45:5 예고)

## 2. 새 시스템 (엔진 쪽 추가)
- **컷신 2.0** (`life.js` Cine): 샷마다 `cam/cam2/look/look2`(배열 또는 시간 함수), `fov/fov2`, `ease`, `shake`, `fadeIn/fadeOut/black`, `title/sub`(장 제목 카드), `music`, `sfx`, `each(t)`(샷 동안 매 프레임), `hour`. 대사는 더빙이 끝날 때까지 기다림. "건너뛰기" 버튼. 오류가 난 샷 함수는 로그만 남기고 계속.
- ~~**한국어 더빙** (`voice.js`)~~ — v10에서 제거됨.: Web Speech API ko-KR. 인물별 목소리(남/여/아이/노인, 높이·빠르기), 감정 16종(e: sad·cry·pray·whisper·shout…), 문장 쪼개 읽기, 음악 덕킹. 대화·컷신·내레이션 카드·그림책 오프닝 전부 읽음. 설정: 더빙 켜기/끄기, 목소리 빠르기, 대사 자동 넘김. 녹음 파일로 바꾸려면 `G.Voice.files[Voice.key(이름, 대사)] = url`.
- **녹음 배경음악** (`audio.js`): `Au.addTracks({ key: { url, loop, fallback } })`. 한 바퀴(loop초)마다 다음 사이클을 예약해 잔향이 겹치며 끊김 없이 반복. 디코딩 버퍼 2개만 유지(LRU), 다음 장 곡 미리 받기, 파일이 안 열리면 절차적 음악으로 대체.
- **튜토리얼 힌트 알약** `UI.hint(text, key, icon)` (+ 아이콘 move/look/eye/tap/jump/run/chain/pray), **에피소드 핫바 버튼** `EP.extra`, 단어 카드(`featCard`의 kick 문구).
- **에피소드 훅**: `EP.camera`(구덩이 안 카메라), `EP.speedMul`(묶임 0.74·차꼬 0.52·수레 2.2), `EP.pose`(플레이어 연출 포즈 `P.cpose`), `EP.rootY`(수레 위), `EP.flats`(달빛 기둥·꿈 빛기둥), `EP.titleMusic`.
- **새 포즈**: bound(묶인 손) · fallen(쓰러짐) · reach(벽 짚기) · mourn(통곡) · tearClothes(옷 찢기) · beg(애원) · grabCloth · present(잔 올리기) · charioteer(수레) · shave · scratchWall · kneelPray. `G.Motion.HOLD_IK_OFF`에 전신 포즈 등록.

## 4. 파일
- `ep_sources/joseph/` 조각을 **a → b → c → d → e_cine → e_cine2 → f** 순서로 cat 하면 `js/ep_joseph.js`.
  - a_map(지형·길·장소·대사 도우미) · b_build(소품·건물·인물 룩) · c_steps(42개 스텝과 대사) · d_world(인물·특수 상호작용·우물/침상·밭·우리·곳간 터·마을)
  - e_cine(포즈·무대 배치 `stage()`·프롤로그~보디발의 집 컷신과 미니게임) · e_cine2(옥·꿈·궁정·꿈속 나일·풍년·흉년·형들) · f_runtime(음악·분위기·업데이트·경계·카메라·수레·동적 메시·오프닝·등록)

## 5. 검증

- `jshots.js`: 주요 장면 화면 캡처(세로 390×844).
